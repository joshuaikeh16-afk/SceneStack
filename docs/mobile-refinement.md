# Mobile experience refinement

Implemented 23 November 2026. This brief supersedes the earlier requirement for management controls on poster cards. The existing Next.js/Supabase architecture, 24 migration files, authentication, database ownership rules and provider adapters were preserved. This refinement applies no hosted migrations, catalog imports, role changes or deployments.

## Current experience

| Area           | Changes                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Home           | Real featured catalog title with licensed backdrop/poster, title, year, category, genres, synopsis, tracking and View Details. Compact mobile presentation followed by category chips and clean discovery shelves. The marketing/scenery hero is no longer rendered. Empty/unavailable catalog states remain explicit.                                                                                 |
| Standard cards | One tappable link containing only 2:3 artwork, a two-line title and category/year. No tracking badge, rating badge, favorites, toolbar or recommendation feedback. This shared contract covers Home, Discover, recommendations, library and related-title cards.                                                                                                                                       |
| Details        | Cinematic backdrop with poster fallback, prominent poster and readable title/metadata, synopsis, primary tracking, separate personal controls, trailers, facts, credits and verified related works when available. Recommendation feedback now lives here. Direct links retain the standalone title page.                                                                                              |
| Rating         | Inline editor within the detail surface; private rating is explicitly labeled apart from SceneStack community scores. Slider/numeric input retain 1.0–10.0 tenth increments, Save Rating, Remove Rating, optimistic updates, error drafts and rollback. Escape closes the editor first and restores focus.                                                                                             |
| Modal          | Full-screen sheet below 768px, spacious desktop dialog, accessible sticky close control, vertical scrolling and safe-area padding. All open dialogs reference-count a body marker that hides mobile navigation until the final dialog closes. Intercepted title navigation has an honest loading sheet; canonical not-found responses remain intact.                                                   |
| Discover       | Clear heading/search, compact categories, advanced-filter sheet, sort, honest per-page result counts, clean grid and matching skeletons. URL-backed filtering is preserved. A stale debounce closure was fixed so typing and then changing category keeps both choices; fractional years are rejected before URL generation.                                                                           |
| Library        | Clear My Library heading, compact scrolling sections/status filters, distinct Favorites, My Collections and Saved Collections, plus existing imported/rated sections and opt-in bulk selection. Search/sort controls wrap on narrow screens.                                                                                                                                                           |
| Collections    | Cover/collage, description, creator, visibility and counts remain. Add Titles sits beside one Manage menu for editing, publishing/unpublishing, sharing and deletion. Empty collections have a direct Add Titles action. Search, category filtering, notes, CAS saves, drag/keyboard/button reordering and separate favorite/save/import semantics remain. Membership checks include paginated titles. |
| Profile        | Real loaded profile/collections and explicit loading/error/unavailable states. An unavailable creator never falls back to the signed-in member’s identity. Published-collection pagination follows the loaded profile; private summaries remain owner-only and have retry feedback.                                                                                                                    |
| Performance    | Browsing cards no longer request private title-state batches. Detail and hero controls load their own user-scoped state and retain the shared mutation cache. No new provider requests, data fixtures or external rating substitutes are introduced.                                                                                                                                                   |

## Browser sign-off still required

Computer use returned no apps or browser tabs. No screenshots, viewport overflow measurement, live OAuth/tracking/upload session, touch test or mobile PWA check is claimed. Review the following in a browser before public release:

| Viewport                          | Required review                                                                                                                                                                                                             |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 320px, 360px, 375px, 390px, 414px | Featured hero leaves room for discovery, two-column poster grid, independent 2.2-card rails, 44px controls, no horizontal document overflow, readable metadata, keyboard/input behavior, safe-area navigation clearance.    |
| 768px                             | Tablet grid/rails, existing navigation breakpoint, modal bounds, collection management and profile wrapping.                                                                                                                |
| Desktop (1366px and 1440px+)      | Spacious modal, backdrop dismissal, Escape, focus trap/restoration, direct title links and browser Back/forward.                                                                                                            |
| All                               | Search/category/filter URL behavior, Watching/Watched/status changes and rollback, rating save/remove, collection creation/editing/reorder, profile loaded/empty/error states and hidden navigation while a dialog is open. |

External provider scores are not stored or exposed by the current approved data contract; they are not invented or presented as SceneStack community ratings. Anime cast/trailers and verified relationships appear only when present in the approved canonical metadata. Adding a licensed source or storage capability for missing fields is separate backend work; this UI refinement does not fake persistence or silently apply a migration.

The [Vercel handoff](vercel-release.md) still governs deployment, callback configuration and remaining live service checks.
