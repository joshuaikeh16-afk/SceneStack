## Operational setup and limits

All 24 migrations are applied. TMDB and MyAnimeList keys are verified, providers are approved/enabled for the operator-confirmed personal/non-commercial use, official TMDB attribution is installed, and 27 real titles populate all six categories. The explicitly chosen Google account is owner/Super Admin. Website deployment and production callback configuration remain pending. Offline metadata copies additionally require explicit provider offline-cache permission. Daily history retention, account lifecycle, and provider worker schedules require operator setup after staging verification. In-memory collection drafts survive in-app navigation but cannot survive a browser process crash or confirmed full reload/close; native leave warnings are best-effort. Private drafts are never persisted to localStorage, sessionStorage, CacheStorage, or public profiles.

The PGlite Auth/Storage stubs do not replace the hosted Supabase integration. Service-worker tests execute the actual worker policy in a simulated harness, not a browser. SceneStack is not claimed production-ready.
